# L2 价值链与业务流程环节台账

> 维护对象：各 L1 业务域下稳定的价值链或业务流程分组。  
> 编码格式：`BA01-P01`。其中 `BA01` 为所属 L1，`P` 表示流程环节。

## 1. 字段标准

| 字段 | 必填 | 填写规则 |
|---|---|---|
| L2 编码 | 是 | `L1 编码-P两位数字` |
| 所属 L1 | 是 | 必须引用 `01_L1_一级业务域.md` 中启用的编码 |
| 环节名称 | 是 | 使用价值链或业务流程语言 |
| 流程位置 | 是 | 说明该环节在业务流程中的前后位置或职责 |
| 主要角色 | 否 | 负责或参与该环节的岗位、部门 |
| 输入与输出 | 否 | 仅记录理解流程所需的主要输入与输出 |
| 页面摘要 | 是 | 30—60 个汉字，不写 Dora 或技术实现 |
| 维护状态 | 是 | 启用、候选、停用 |
