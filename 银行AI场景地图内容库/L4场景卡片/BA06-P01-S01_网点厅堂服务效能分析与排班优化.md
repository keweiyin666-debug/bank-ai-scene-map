# BA06-P01-S01 网点厅堂服务效能分析与排班优化

> 公开维护投影，不包含客户原件或内部证据。正式新增事实须回到本地完整源卡审核。

| 字段 | 内容 |
|---|---|
| 主业务域 | BA06 渠道与客户服务 |
| L2 | BA06-P01 渠道运营 |
| L3 | 无 |
| 主要使用角色 | 运营管理人员、厅堂服务项目人员、支行管理人员 |
| 触发时点 | 月度厅堂效能复盘、客流高峰前、网点辅导与排班调整时 |
| 业务任务 | 监测客流与等候时长→比较同类型网点→从业务、柜员和客户维度归因→识别高峰时点和超时交易→形成辅导与排班建议 |
| 定义 | 运营管理人员按周期分析网点客流、等候与办理效率，定位影响因素并形成网点辅导、客户分流和排班优化建议。 |
| Before | 网点效能多依赖零散统计和事后反馈，难以横向比较同类网点，也难以定位超时业务、柜员和客流高峰的影响。 |
| After | BI看板统一展示客流、等候、业务量和超时情况，并按业务、柜员、客户和网点类型下钻，管理人员确认辅导和排班动作。 |
| 用户反馈（预期体验） | “我能直接看到哪家网点、哪个时点和哪类业务拖慢了效率，辅导和排班都有数据依据。” |
| 效率价值（V03 实测参考） | 作品材料显示2025年6月全行平均等候时长为400秒，较5月缩短60.56秒。 |
| 质量/风险价值（V00 待确认） | 需补充超时交易识别准确率、数据完整率和异常复核规则。 |
| 经营/管理价值（V00 待确认） | 需补充辅导完成率、排班调整覆盖率、客户满意度或营销产出观察指标。 |
| 数据范围 | 网点客流、客户等候时长、业务办理时长、高频交易、超时交易、柜员、客户年龄、营销积分和网点类型。 |
| 输出 | 厅堂效能看板、同类网点对比、问题清单、高峰趋势、辅导重点和排班建议。 |
| 人工确认 | 确认异常原因、网点辅导重点、客户分流方式和人员排班方案。 |
| 协作与动作 | 当前以BI指标和看板分析为主；后续可由Dora或联合Agent生成归因摘要与排班建议。 |
| 实现范围 | 已覆盖2025年6月客流、等候、业务量和部分归因分析；自动趋势预测、排班优化和效果回录尚未形成。 |
| 能力边界 | 客流与等候相关性不等同因果；排班和分流措施需结合服务规范人工审定。 |
