# BA03-P04-S01 企业资金账户与收支监测

> 公开维护投影，不包含客户原件或内部证据。正式新增事实须回到本地完整源卡审核。

| 字段 | 内容 |
|---|---|
| 主业务域 | BA03 公司金融 |
| L2 | BA03-P04 企业财资服务（财资大管家 / CBS） |
| L3 | 无 |
| 主要使用角色 | 企业客户的财务/资金负责人、获授权企业主；银行公司金融/交易银行团队为服务提供方。 |
| 触发时点 | 企业日常资金盘点、收支核对及经营复盘；小企业主适用范围需结合授权账户和实际需求验证。 |
| 业务任务 | 企业授权账户→程序汇集余额和交易→按主体、币种与时点汇总→核对异动→企业负责人决定资金安排。 |
| 定义 | 银行通过企业财资服务平台，为企业主及财务人员汇总获授权的跨行账户、余额与收支，帮助企业查看资金分布、核对异动并形成经营判断。 |
| Before | 企业账户与收支信息分散，财务人员需汇总核对后才能判断资金分布；逐户登录及手工拼表的具体成本仍需访谈核实。 |
| After | BI与受控程序统一展示授权账户、余额和收支明细；建议叠加AI解释波动与生成摘要，企业财务核实后决定资金动作。 |
| 用户反馈（预期体验） | “我能在一个视图里看清企业的钱在哪里、怎么流动，发现异常后再核对原始交易。” |
| 效率价值（V00 待确认） | 统一账户与收支查询，减少重复汇总；查询次数、准备时长和目标周期待企业试点确认。 |
| 质量/风险价值（V00 待确认） | 按授权账户追溯交易与余额，辅助核对异常；授权覆盖率、匹配错误率及复核范围待确认。 |
| 经营/管理价值（V00 待确认） | 资金分布与变化支持企业资金安排；闲置资金识别、资金集中率和服务采纳目标待确认。 |
| 数据范围 | 企业管理权限内的单位、时间、币种、银行、账户、余额变化、交易明细、收支与交易排行。 |
| 输出 | 企业资金账户全景、收支明细、余额趋势、交易排行与待核异常清单。 |
| 人工确认 | 企业确认主体和账户授权、统计口径及异常事实，决定资金用途；银行核验数据服务权限，不代替企业批准资金动作。 |
| 协作与动作 | 材料为企业财资BI/规则分析。建议C02嵌入企业财资平台：Dora承担授权问数、解释和摘要；专业程序负责权限、统计、提醒与记录，企业负责人确认后续动作。AI尚无部署证据，不默认启用联合Agent。 |
| 实现范围 | 材料支持账户、资金余额、收支及排行等BI分析；AI解释、自动提醒和业务执行均未被证实。 |
| 能力边界 | 公司金融对客企业财资服务（CBS），不是银行内部财务/ALM。不得跨企业越权汇总或跨币种直接相加；不执行资金划拨、支付或投资。 |

## 部门关系

- 交易银行部：主责；顾问建议；approved。适用：CBS通用职责建议；不能写成银行内部计财任务，也不承诺代客支付。
- 公司金融部：协同；顾问建议；approved。适用：CBS通用职责建议；不能写成银行内部计财任务，也不承诺代客支付。
