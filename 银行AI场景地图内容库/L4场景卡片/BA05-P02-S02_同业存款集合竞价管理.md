| 业务任务 | 集中收集报价，按资金需求与策略确定中标并约束执行 |
| 定义 | 金融市场部在日常竞价窗口集中处理分行同业报价申请，依据批准策略确定中标并跟踪履约及警告记录。 |
| Before | 分行分散争取同业存款可能引发价格竞争，资金需求和定价缺少统一协调，需总行集中管理。 |
| After | 案例材料由分行收集报价并提交申请，总行按价格、规模、期限和时间等要素确定中标，对中标未执行分行记录警告及申请约束。 |
| 用户反馈（预期体验） | “我希望各分行报价能在同一窗口比较，中标和未执行处理都有一致规则可查。” |
| 效率价值（V00） | 集中窗口可减少报价汇总往返，需补单日处理时长、申请量和人工复核工时。 |
| 质量/风险价值（V00） | 按价格规模期限等规则筛选可增强一致性，需补报价差错率、越权阻断与结果复核记录。 |
| 经营/管理价值（V00） | 有助统一控制同业存款成本与执行纪律，需补加权资金成本、履约率及比较基线，不能承诺利率下降。 |
| 数据范围 | 同业金额利率报价、规模期限、申请时间、资金需求和执行记录 |
| 输出 | 竞价申请、汇总候选、中标结果与未执行警告 |
| 人工确认 | 总行金融市场部审定策略和中标结果，核实未执行原因及处分边界；异常报价退回核查。 |
