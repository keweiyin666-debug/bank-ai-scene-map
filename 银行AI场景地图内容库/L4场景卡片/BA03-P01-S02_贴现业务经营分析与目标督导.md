| 字段 | 内容 |
|---|---|
| 主业务域 | BA03 公司金融 |
| L2 | BA03-P01 客户拓展与经营 |
| L3 | 无 |
| 主要使用角色 | 公司业务管理人员、支行管理人员、票据业务人员和客户经理 |
| 触发时点 | 日常经营监测、月度复盘、目标制定和机构督导时 |
| 业务任务 | 汇总贴现规模、户数和利息收入→按机构与客户经理比较→分析趋势和差距→设定目标→形成督导与协同事项 |
| 定义 | 公司业务管理人员按周期分析贴现规模、客户和收入表现，定位机构与客户经理差距并形成目标督导事项。 |
| Before | 贴现规模、户数、收入和人员业绩分散在不同统计表中，经营复盘与目标督导依赖人工汇总和经验判断。 |
| After | BI看板统一展示核心指标、趋势、机构和客户经理表现，管理人员据此确认目标、差距和督导重点。 |
| 用户反馈（预期体验） | “我能快速看清贴现业务增长来自哪里、哪些机构需要跟进，不再临时拼表后才开始讨论。” |
| 效率价值（V00 待确认） | 需补充贴现经营材料准备时长、更新频率和目标周期。 |
| 质量/风险价值（V00 待确认） | 需补充核心指标口径一致率和异常数据复核要求。 |
| 经营/管理价值（V00 待确认） | 需补充目标达成改善、落后机构跟进率或贴现客户增长指标。 |
| 数据范围 | 贴现规模、贴现户数、贴现利息收入、机构和客户经理业绩、历史趋势与目标。 |
| 输出 | 经营看板、趋势分析、机构与客户经理排名、目标差距和督导事项。 |
| 人工确认 | 确认经营目标、机构差距、考核口径和督导要求。 |
