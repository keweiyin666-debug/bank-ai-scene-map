# L1 一级业务域台账

> 维护对象：银行 AI 场景地图的一级导航。  
> 编码格式：`BA01`—`BA99`。  
> 变更要求：新增、拆分或合并业务域前，先评估对全部 L2—L4 引用的影响。

## 1. 字段标准

| 字段 | 必填 | 填写规则 |
|---|---|---|
| L1 编码 | 是 | `BA` 加两位数字，保持稳定 |
| 业务域名称 | 是 | 使用银行通用业务语言 |
| 业务定义 | 是 | 说明该业务域覆盖的主要业务职责 |
| 纳入范围 | 是 | 列出主要价值链或职能范围 |
| 不纳入范围 | 否 | 说明容易混淆但应归入其他业务域的内容 |
| 页面摘要 | 是 | 40—80 个汉字，用于业务域标题下说明 |
| 维护状态 | 是 | 启用、待调整、停用 |
| 最后更新 | 是 | `YYYY-MM-DD` |
